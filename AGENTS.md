# AGENTS.md

Guidance for any AI agent working in this repository.

## UI work

Read and follow `DESIGN.md` before any UI change: the home page (`public/home.html`), the design system showcase (`public/design-system.html`), the stylesheets in `public/assets/`, and the Swagger UI description (`SERVICE_DESCRIPTION` in `constants/application_constants.py`). Colours come from the tokens in `public/assets/tokens.css`, written in hex.
